# 🚀 Como fazer deploy do projeto na Vercel (via arquivo ZIP)

Este guia vai te ensinar a colocar o site no ar usando a Vercel de forma simples.

---

## 📦 1. Baixar e extrair o projeto

1. Faça o download do arquivo `.zip` enviado
2. Extraia o arquivo no seu computador
3. Abra a pasta do projeto (onde estão os arquivos como `index.html`)

---

## 🌐 2. Acessar a Vercel

1. Acesse: https://vercel.com
2. Clique em **"Sign Up"** (ou "Login" se já tiver conta)
3. Você pode entrar com:

   * Google
   * GitHub
   * Email

---

## ☁️ 3. Fazer o deploy do projeto

1. Após entrar, clique em **"Add New Project"**
2. Clique em **"Browse"** ou arraste a pasta do projeto
3. Selecione a pasta que você extraiu

---

## ⚙️ 4. Configuração (importante)

Na maioria dos casos, NÃO precisa mudar nada.

Só confira:

* Framework Preset: **Other**
* Root Directory: deixe padrão

---

## 🚀 5. Publicar o site

1. Clique em **"Deploy"**
2. Aguarde alguns segundos

---

## 🔗 6. Acessar o site

Após o deploy, a Vercel vai gerar um link tipo:

https://seu-projeto.vercel.app

É só clicar e seu site já estará online 🎉

---

## ❗ Dicas importantes

* Se alterar algo no projeto, será necessário fazer upload novamente
* Guarde o link gerado
* Caso algo dê erro, tente subir novamente
